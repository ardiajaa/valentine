# valentine

Sebuah halaman web sederhana untuk ucapan Hari Valentine.

## Demo

Lihat demo langsung di [ucapan-untuk-kamu.vercel.app](https://ucapan-untuk-kamu.vercel.app/) [2].

## Teknologi

Proyek ini dibuat menggunakan HTML.

## Cara Menjalankan Secara Lokal

Untuk menjalankan proyek ini di komputer Anda:

1. Clone repositori ini:
   ```bash
   git clone https://github.com/ardiajaa/valentine.git
   ```
2. Buka folder proyek.
3. Buka file `index.html` di browser web pilihan Anda.
